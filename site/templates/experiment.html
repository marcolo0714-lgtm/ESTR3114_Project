Experiment 1 · Token prediction and sentiment

Do the two tasks help each other?

A comparison of single-task training, weighted joint training, and PCGrad on a shared GPT-2 backbone.

Main finding. At 6,000 steps, the three trained sentiment methods reach about 70% test macro-F1. Joint and PCGrad retain much stronger token prediction than sentiment-only. PCGrad's extra classification gain is negligible, while its recorded runtime is about 33% higher than joint.

Four training methods

The backbone parameters θ are shared. The token head and sentiment head have separate parameters. Let LT be next-token loss, LS sentiment cross-entropy, gT = ∇θLT, and gS = ∇θLS.

MethodTraining objective or shared gradientMeaning
Token-onlymin LTTrain the backbone and token head. The sentiment head is untrained.
Sentiment-onlymin LSTrain the backbone and sentiment head. Token-head parameters receive no task gradient.
Jointmin (LT + λLS)
g = gT + λgS		Combine the objectives with a sentiment weight λ.
PCGradg = g′T + λg′SRemove conflicting shared-gradient components before combining. Private heads receive their ordinary task gradients with the same sentiment weight.

PCGrad projection

When gT · gS < 0, both tasks are projected against the original peer gradient:

g′T = gT − gT · gS‖gS‖² gS
g′S = gS − gS · gT‖gT‖² gT

Otherwise the gradients are unchanged. Projection is skipped for zero-norm gradients. AdamW applies the combined gradient after norm clipping.

A simple 2D example

Suppose the two shared task gradients are gT = (2, 0) and gS = (−1, 1). Use λ = 1 to keep the arithmetic simple. Their dot product is 2(−1) + 0(1) = −2 < 0, so they conflict.

  • Token-only: use gT = (2, 0).
  • Sentiment-only: use gS = (−1, 1).
  • Joint: add them directly: gjoint = (2, 0) + (−1, 1) = (1, 1).
  • PCGrad: project both gradients against the original peer, then add them:

‖gT‖² = 4,   ‖gS‖² = 2

g′T = gT − (−2 / 2) gS = (2, 0) + (−1, 1) = (1, 1)

g′S = gS − (−2 / 4) gT = (−1, 1) + (1, 0) = (0, 1)

gPCGrad = g′T + g′S = (1, 2)

This illustrates shared-gradient surgery before clipping and AdamW; it is not a measured training step. With λ = 3 instead, the same example gives gjoint = (−1, 3) and gPCGrad = (1, 4). Private task heads keep their ordinary weighted task gradients.

What the four metrics mean

MetricDefinitionInterpretation
Token loss ↓LT = −(1/N) ∑ log p(xi | x<i)Mean negative log probability of each correct next token, including EOS and excluding padding. Lower is better.
Perplexity ↓PPL = exp(LT)Token loss on an exponential scale. It is derived from token loss, not independent evidence.
Accuracy ↑(1/M) ∑ 1[ŷi = yi]Fraction of tweets with the correct sentiment label.
Macro-F1 ↑F1c = 2TPc / (2TPc + FPc + FNc)Macro-F1 = (1/3) ∑ F1cAverage F1 across negative, neutral, and positive classes, with equal weight per class. Undefined scores are zero.

N counts valid next-token targets; M counts tweets. TP, FP, and FN are true positives, false positives, and false negatives. Always predicting neutral gives 48.33% test accuracy but only about 21.72% macro-F1.

What the results support

  • Training budget mattered. At λ = 3, joint macro-F1 rises from 53.39% at 1,000 steps to 70.13% at 6,000; PCGrad rises from 52.86% to 70.14%. Variation across the three seeds becomes much smaller.
  • The schedule changed too. The longer runs started fresh. Warmup increased from 100 to 600 steps, and the learning-rate decay endpoint changed. This comparison changes both budget and schedule.
  • The task weight changes the trade-off. At 1,000 steps, higher λ improves sentiment while making token prediction worse. Only λ = 3 was evaluated at 6,000 steps.
  • Classification is essentially tied at 6,000 steps. PCGrad beats joint by only 0.0102 test macro-F1 percentage points on average and loses in one of the three seeds. Sentiment-only actually has higher mean final validation macro-F1.
  • PCGrad has a small token benefit. Its test perplexity is lower than joint in all three seeds, by 0.5068 on average (about 0.405%). Both multitask methods retain much stronger token prediction than sentiment-only.
  • Extra computation has a cost. Joint averages 23.75 minutes per run and PCGrad 31.61 minutes, about 33.07% more. Timers include training and validation, excluding setup, final test evaluation, and checkpoint saving.
  • Conflicts are usually weak. Raw shared gradients conflict in about 40% of diagnostic samples, but mean absolute cosine is only about 0.039. This is consistent with the nearly overlapping joint and PCGrad learning curves.

Limits of the comparison

  • Three seeds and one dataset do not establish statistically significant or universal superiority. Zoomed plots magnify small differences.
  • Aggregate test results use the fixed final step, rather than the best validation checkpoint. The original evaluations did not retain per-example predictions for error analysis.
  • Sentiment-only minimizes LS, whereas joint minimizes LT + 3LS. The comparison changes the auxiliary objective and gradient scale.
  • The demo checkpoints were saved in separate seed-44 reruns. Their own test summaries are displayed above; small numerical differences from the original seed-44 results are possible.
  • Training was based on tweets. Long documents, other languages, and arbitrary sentences can behave differently. Example predictions are illustrations, not a substitute for held-out evaluation.
